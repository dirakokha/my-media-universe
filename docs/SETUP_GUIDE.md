# راهنمای راه‌اندازی — دنیای رسانه‌ای من

این راهنما برای **شما** نوشته شده، نه برای برنامه‌نویس. هیچ نیازی نیست کد بنویسید.
فقط کافی است به‌ترتیب مراحل را انجام دهید و در جاهایی که نوشته «کپی کنید»، همان
متن را بدون تغییر جای‌گذاری کنید.

> ⚠️ **قانون طلایی:** هیچ رمز، کلید یا کلمهٔ عبوری را در چت، ایمیل یا پیامک برای
> هیچ‌کس (حتی هوش مصنوعی) نفرستید. آن‌ها را فقط در پنل خودتان در بخش مشخص‌شده
> وارد کنید.

---

## ۰) قبل از هر چیز: چه چیزی لازم دارید؟

| مورد | هزینه | توضیح |
| --- | --- | --- |
| حساب Cloudflare | ۰ | میزبان برنامه و پایگاه داده |
| حساب TMDB | ۰ | اطلاعات فیلم و سریال |
| حساب Google | ۰ | پشتیبان‌گیری در Google Drive |
| حساب Resend | ۰ (تا ۳۰۰۰ ایمیل در ماه) | ارسال ایمیل تأیید و بازیابی رمز |
| دامنه (اختیاری) | ۰ اگر از زیردامنهٔ رایگان Cloudflare استفاده کنید | `my-media.example.workers.dev` رایگان است |

همه‌چیز رایگان است. هیچ‌کجا کارت بانکی لازم نیست. اگر جایی کارت بانکی خواست،
یعنی در مسیر اشتباهی هستید — برگردید و مرحله را دوباره بخوانید.

---

## ۱) ساخت حساب Cloudflare

1. به <https://dash.cloudflare.com/sign-up> بروید.
2. ایمیل و یک رمز عبور قوی بسازید (رمز را در جای امن نگه دارید).
3. ایمیل تأیید را باز کنید و روی لینک کلیک کنید.

**نتیجه:** یک حساب Cloudflare دارید. فعلاً کاری با آن نمی‌کنیم.

---

## ۲) گرفتن کلید TMDB

1. به <https://www.themoviedb.org/signup> بروید و حساب بسازید.
2. وارد شوید و به <https://www.themoviedb.org/settings/api> بروید.
3. در بخش **API** روی **Create** یا **Request an API Key** کلیک کنید.
4. نوع را **Developer** انتخاب کنید و فرم را پر کنید (موافقت‌نامه را بخوانید).
5. کلیدی که با عنوان **API Read Access Token** می‌بینید را کپی کنید
   (یک متن خیلی طولانی که با `eyJ...` شروع می‌شود).

**نکته:** این کلید فقط در سرور استفاده می‌شود. هرگز آن را در چت نفرستید.

---

## ۳) ساخت پروژهٔ Google برای پشتیبان‌گیری

این بخش برای «اتصال به Google Drive» لازم است. اگر فعلاً نمی‌خواهید پشتیبان‌گیری
را فعال کنید، می‌توانید از آن رد شوید و بعداً برگردید (بقیهٔ برنامه کار می‌کند).

1. به <https://console.cloud.google.com/projectcreate> بروید.
2. یک نام بگذارید، مثلاً `my-media-universe` و روی **Create** کلیک کنید.
3. در منوی بالا مطمئن شوید همین پروژه انتخاب شده است.
4. به <https://console.cloud.google.com/apis/library/drive.googleapis.com> بروید و
   روی **Enable** کلیک کنید.
5. به <https://console.cloud.google.com/apis/credentials> بروید.
6. روی **+ Create credentials → OAuth client ID** کلیک کنید.
   - اگر گفت اول باید «OAuth consent screen» بسازید: **External** را انتخاب کنید،
     نام برنامه را بنویسید، ایمیل خودتان را اضافه کنید و ذخیره کنید.
   - در بخش **Test users** ایمیل خودتان را اضافه کنید (تا زمانی که برنامه را
     منتشر نکرده‌اید، فقط همین ایمیل اجازهٔ اتصال دارد).
7. در **Application type** گزینهٔ **Web application** را انتخاب کنید.
8. در **Authorized redirect URIs** این نشانی را اضافه کنید (به‌جای `YOUR-SITE`
   نشانی سایت خودتان را بگذارید — در مرحلهٔ ۶ می‌فهمید چه است):
   ```
   https://YOUR-SITE/api/backup/google/callback
   ```
9. روی **Create** کلیک کنید. **Client ID** و **Client Secret** را کپی کنید و
   در جای امن نگه دارید.

## ۴) ساخت کلید ارسال ایمیل (Resend)

1. به <https://resend.com/signup> بروید و حساب بسازید.
2. به <https://resend.com/api-keys> بروید و روی **Create API Key** کلیک کنید.
3. یک نام بگذارید، دسترسی را **Sending access** بگذارید و بسازید.
4. کلید را کپی کنید (فقط یک بار نشان داده می‌شود).
5. برای اینکه ایمیل‌ها در صندوق وارد شوند (نه پوشهٔ اسپم)، باید یک دامنه تأیید کنید:
   به <https://resend.com/domains> بروید، **Add Domain** را بزنید و رکوردهای DNS
   را در Cloudflare اضافه کنید. اگر فعلاً دامنه ندارید، می‌توانید از نشانی
   `onboarding@resend.dev` استفاده کنید — فقط برای تست.

## ۵) یک بار راه‌اندازی اولیه (این بخش را عامل/برنامه‌نویس انجام می‌دهد)

اگر خودتان می‌خواهید انجام دهید، Node.js را از <https://nodejs.org> نصب کنید
(نسخهٔ LTS)، سپس در پوشهٔ پروژه این دستورها را یکی‌یکی اجرا کنید:

```bash
npm install
npx wrangler login
```

در دستور دوم یک صفحهٔ مرورگر باز می‌شود؛ روی **Allow** کلیک کنید.

---

## ۶) ساخت پایگاه داده و انتشار

```bash
npx wrangler d1 create mmu-db
```

خروجی یک خط شبیه این می‌دهد:

```
database_id = "1a2b3c4d-5e6f-7890-abcd-ef1234567890"
```

این شناسه را جای `00000000-0000-0000-0000-000000000000` در فایل `wrangler.jsonc`
بگذارید (بخش `d1_databases`). سپس:

```bash
npx wrangler d1 migrations apply mmu-db --remote
npm run build
npx wrangler deploy
```

آدرس سایت در خروجی آخر نمایش داده می‌شود، مثلاً:
`https://my-media-universe.<your-subdomain>.workers.dev`

**همین آدرس را جای `YOUR-SITE` در مرحلهٔ ۳ (بند ۸) بگذارید و ذخیره کنید.**

---

## ۷) وارد کردن کلیدها در Cloudflare (مهم‌ترین بخش)

1. به <https://dash.cloudflare.com/> بروید.
2. از منوی کنار **Workers & Pages** را انتخاب کنید.
3. روی برنامهٔ **my-media-universe** کلیک کنید.
4. به تب **Settings** بروید و بخش **Variables and Secrets** را پیدا کنید.
5. برای هر مورد زیر روی **Add** بزنید، نوع را **Secret** انتخاب کنید و مقدار را
   وارد کنید. **هیچ‌کدام را در چت نفرستید.**

| نام | مقدار |
| --- | --- |
| `TMDB_API_KEY` | همان کلید طولانی از مرحلهٔ ۲ |
| `GOOGLE_CLIENT_ID` | از مرحلهٔ ۳ |
| `GOOGLE_CLIENT_SECRET` | از مرحلهٔ ۳ |
| `RESEND_API_KEY` | از مرحلهٔ ۴ |
| `EMAIL_FROM` | مثلاً `My Media Universe <no-reply@yourdomain.com>` |
| `ENCRYPTION_KEY` | یک متن ۳۲ بایتی — برای ساختنش در ترمینال بزنید `openssl rand -base64 32` و خروجی را کپی کنید |
| `ADMIN_BOOTSTRAP_SECRET` | یک رمز طولانی و تصادفی — فقط برای ساختن اولین مدیر |
| `APP_BASE_URL` | آدرس سایت از مرحلهٔ ۶، بدون `/` آخر |

همچنین در همان صفحه یک متغیر **Plain text** (نه Secret) اضافه کنید:

| نام | مقدار |
| --- | --- |
| `ENV` | `production` |

بعد از ذخیره، یک بار دیگر `npx wrangler deploy` را اجرا کنید تا تنظیمات اعمال شود.

## ۸) ساخت اولین حساب مدیر

1. سایت را باز کنید: `https://<your-site>.workers.dev`
2. به `/setup` بروید.
3. نام کاربری، ایمیل و رمز عبور را وارد کنید.
4. در بخش «رمز راه‌اندازی» همان `ADMIN_BOOTSTRAP_SECRET` را وارد کنید.
5. روی **ساخت حساب مدیر** کلیک کنید.

**همین لحظه:** به تنظیمات Cloudflare برگردید و `ADMIN_BOOTSTRAP_SECRET` را
**حذف** کنید. این کلید فقط برای همین یک بار است.

> 🔑 **کلید بازیابی** را که بعد از ساخت حساب نشان داده می‌شود، در یک جای امن
> (مثلاً یک فایل متنی رمزگذاری‌شده یا کاغذ در کشو) بنویسید. این کلید فقط
> **یک بار** نمایش داده می‌شود و اگر رمزتان را فراموش کنید، تنها راه بازگشت
> همین است.

---

## ۹) دعوت دیگران (اختیاری)

1. با حساب مدیر وارد شوید.
2. از منو **مدیریت دعوت‌ها** را باز کنید.
3. روی **ساخت کد دعوت** کلیک کنید و (اختیاری) ایمیل فرد را بنویسید.
4. کد را برای آن فرد بفرستید. هر کد **فقط یک بار** قابل استفاده است و بعد از
   مدتی منقضی می‌شود.
5. او در `/register` با آن کد حساب می‌سازد. داده‌های او کاملاً از داده‌های شما
   جدا است.

---

## ۱۰) اتصال Google Drive

1. با حساب خودتان وارد شوید و به **تنظیمات** بروید.
2. بخش **Google Drive** را باز کنید و **اتصال** را بزنید.
3. صفحهٔ Google باز می‌شود؛ حساب خودتان را انتخاب کنید و اجازه دهید.
   (چون پروژه در حالت «Test» است، ممکن است هشدار بدهد — روی **Advanced →
   Go to … (unsafe)** کلیک کنید. این هشدار فقط برای پروژه‌های تأییدنشده است.)
4. برمی‌گردید به تنظیمات و پیام «اتصال برقرار شد» را می‌بینید.
5. **پشتیبان‌گیری خودکار** را روشن کنید تا هر روز یک نسخه در پوشهٔ
   `My Media Universe` در Google Drive شما ساخته شود.

---

## ۱۱) نصب روی گوشی (PWA)

**اندروید (Chrome):**

1. سایت را در Chrome باز کنید.
2. منوی سه‌نقطه → **Add to Home screen** / **Install app**.
3. تأیید کنید. حالا مثل یک برنامهٔ معمولی از صفحهٔ اصلی باز می‌شود.

**ویندوز (Edge یا Chrome):**

1. سایت را باز کنید.
2. آیکون نصب در نوار آدرس (کنار ستاره) را بزنید → **Install**.

## ۱۲) اگر چیزی کار نکرد

| مشکل | راه‌حل |
| --- | --- |
| «اتصال به TMDB هنوز تنظیم نشده است» | کلید `TMDB_API_KEY` را در Cloudflare اضافه کنید و دوباره deploy کنید |
| ایمیل تأیید نمی‌رسد | پوشهٔ اسپم را چک کنید؛ در تنظیمات Resend دامنه را تأیید کنید |
| «اتصال به Google Drive هنوز پیکربندی نشده است» | `GOOGLE_CLIENT_ID` و `GOOGLE_CLIENT_SECRET` اضافه نشده‌اند |
| صفحهٔ Google خطای `redirect_uri_mismatch` داد | نشانیِ `Authorized redirect URIs` در پروژهٔ Google دقیقاً باید `https://<your-site>/api/backup/google/callback` باشد |
| سایت بالا نمی‌آید | در Cloudflare → Workers & Pages → برنامه → **Deployments** آخرین وضعیت را ببینید |
| رمز عبور را فراموش کردم | از **ورود → رمز عبور را فراموش کرده‌ام** استفاده کنید؛ اگر ایمیل هم در دسترس نیست، از **کلید بازیابی** در `/recover` استفاده کنید |
